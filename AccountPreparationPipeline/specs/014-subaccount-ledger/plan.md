# Implementation Plan: Sub-Account Consolidated Ledger

**Branch**: `014-subaccount-ledger` | **Date**: 2026-07-03 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/014-subaccount-ledger/spec.md`

## Summary

Add a new `create_subaccount_ledger` pipeline mode that accepts one or more capital ledger XLSXs and zero or more income ledger XLSXs (all produced by `create_ledger`) and produces a single XLSX with one row per unique (date, sub-account) pair across all inputs. Each row carries cumulative `book_cost` and `quantity` (from buy/sell/lodgement), and `total_income` (from dividends). Cash sub-account rows from income ledgers are excluded; Cash rows from capital ledgers produce rows where `quantity == book_cost == running cash balance` and `total_income == 0`.

### A2: engine.py — SubAccountLedgerEngine

```python
class SubAccountLedgerEngine:
    def run(
        self,
        capital_dfs: list[pd.DataFrame],
        income_dfs: list[pd.DataFrame],
    ) -> pd.DataFrame:
        ...
```

**Three-pass computation** (see data-model.md computation flow):

**Pass 1 — Equity positions** (buy/sell/lodgement from all ledgers, excluding income-ledger Cash):
- Concatenate all capital + income DataFrames, with income-ledger Cash rows removed
- Filter to equity actions: `action in {buy, sell, lodgement}` AND `sub_account != Cash`
- Per row: `bv_contrib = TV` (for buy/sell) or `bv_contrib = -TV` (for lodgement; TV is negative)
- Per row: `qty_contrib = TQ`
- Group by (date, sub_account), sum `bv_contrib` and `qty_contrib`
- Sort by date within each sub_account group; cumsum per sub_account

**Pass 2 — Dividend income** (from all ledgers, excluding income-ledger Cash):
- Filter to `action == dividend` AND `sub_account != Cash` (from all input DataFrames, income-ledger Cash already excluded)
- Per row: `income_contrib = TV`
- Group by (date, sub_account), sum `income_contrib`
- Sort by date within each sub_account group; cumsum per sub_account

**Pass 3 — Cash balance** (all actions, capital ledgers only):
- Take only capital DataFrames; filter to `sub_account == Cash`
- Per row: `cash_contrib = TV` (all action types)
- Group by date, sum `cash_contrib`
- Cumsum; output as sub_account="Cash", book_cost=quantity=cumulative, total_income=0

**Merge**:
- Outer-join equity (Pass 1) with income (Pass 2) on (date, sub_account); fill NaN with 0
- Concatenate with Cash rows (Pass 3)
- Sort by (date, sub_account)
- Return result[OUTPUT_COLUMNS]

**Empty-input guard**: If all passes yield empty DataFrames, return empty DataFrame with OUTPUT_COLUMNS.
